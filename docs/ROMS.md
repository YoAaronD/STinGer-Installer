# ROMs for STinGer's games

STinGer doesn't ship ROMs. Update All can switch on the Arcade ROMs database
(zakk4223/ArcadeROMsDB_MiSTer); this is how far that gets you, game by game.
Full list: [`roms.csv`](roms.csv). Regenerated with every database build.

| Status | Games | Meaning |
| --- | --- | --- |
| covered | 253 | Everything it needs comes with the ROMs database |
| parent only | 86 | Only the parent set is there (typical for Japanese versions). Works if those zips are merged sets; otherwise supply the clone zip |
| partial | 53 | Some files are there, but not the game itself (e.g. GunNail: `nmk004.zip` yes, `gunnail.zip` no) |
| missing | 174 | Nothing for it in the ROMs database: supply the zips yourself |
| no zip listed | 10 | The MRA names no zip (homebrew or built-in) |
